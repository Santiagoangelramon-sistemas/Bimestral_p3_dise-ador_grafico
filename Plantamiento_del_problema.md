# Plantamiento del problema
## KIRA DREAMER STUDIO

### 1. El Problema (¿Qué está pasando?)
El problema central es que Kira Dreamer Studio, al ser una productora de animación independiente, carece de una plataforma web propia, centralizada e interactiva que le permita dar a conocer su marca, interactuar de manera directa con su comunidad y vender sus productos y servicios de manera automatizada
.
Actualmente, el estudio depende únicamente de redes sociales de terceros (como YouTube, Instagram y X) para difundir sus contenidos artísticos y bocetos [Image 1]. Esta fragmentación hace que los seguidores tengan que saltar de una red a otra sin un punto de encuentro oficial. Al no contar con un sitio web con base de datos, resulta imposible gestionar de manera segura cuentas de usuarios, automatizar la descarga de archivos digitales, o procesar carritos de compra e inventarios de mercancía física de forma personalizada y directa [Image 1, 11].
### 2. Las Causas (¿Por qué ocurre este problema?)
Desde el punto de vista técnico y de recursos, este problema se origina por las siguientes causas:
- Falta de una infraestructura web integrada: Al estar iniciando como una empresa indie
, el estudio no cuenta con un sistema que conecte una interfaz atractiva (frontend) con un motor de almacenamiento de datos robusto (backend) para guardar información dinámica
.
- Dependencia absoluta de plataformas externas: El portafolio y los avances de animación dependen totalmente de algoritmos de terceros (como YouTube e Instagram) [Image 1], lo que limita la personalización de la experiencia del usuario y no permite recopilar bases de datos de clientes interesados.
- Separación de servicios y productos: Las páginas del sitio, como la visualización de animaciones (Servicios_y_Videos.html), el acceso a recursos artísticos (Productos_Digitales.html) y la venta de mercancía oficial (Productos_Físicos_y_Mercancía.html), se encuentran desconectadas o estáticas, sin un software intermedio que unifique las acciones de los usuarios
.
### 3. Las Consecuencias (¿Qué pasa si no se soluciona?)
Si no desarrollamos una solución tecnológica para el estudio, las consecuencias para el emprendimiento serán graves:
- Pérdida de ingresos y ventas potenciales: Los fans interesados en comprar ropa oficial (sudaderas, camisetas) o adquirir licencias de herramientas digitales de dibujo no dispondrán de un método dinámico para gestionar sus pedidos o cotizaciones, lo que disminuye las ventas del estudio.
- Falta de seguridad e integridad de la información: Al no tener una base de datos relacional y segura, si el estudio intentara registrar compras o datos en archivos de texto plano, la información quedaría vulnerable a pérdidas, redundancias o accesos no autorizados
.
- Baja fidelización de la comunidad: Los espectadores simplemente consumirán el contenido de forma pasiva en redes externas [Image 1], pero no podrán registrarse como usuarios oficiales del estudio, perdiendo la oportunidad de recibir contenido exclusivo o acumular beneficios en su cuenta personal.
### 4. El Aporte (¿Cómo lo solucionamos desde la especialidad de sistemas?)
Nuestro aporte como técnicos en sistemas es diseñar e implementar un sistema web responsive y dinámico con base de datos para centralizar la operación de Kira Dreamer Studio
:
- Diseño visual moderno y responsive (Frontend): Crearemos la interfaz utilizando HTML y Tailwind CSS
. Usaremos sus clases de utilidad prefabricadas —que funcionan como piezas de LEGO— para asegurar que el sitio sea responsive y se adapte automáticamente al tamaño de pantallas de celulares, tablets y computadoras
. El sitio contará con un index principal y 5 páginas adicionales bien estructuradas
.
- Interactividad y Base de Datos (Backend): Diseñaremos el modelo Entidad-Relación y lo programaremos físicamente en phpMyAdmin
. Usando un servidor local XAMPP y el lenguaje PHP, crearemos páginas de acceso seguro para que los clientes se registren dinámicamente, guarden sus cotizaciones de mercancía y accedan a descargas en tiempo real
.
- Despliegue real (Hosting): Finalmente, publicaremos el sitio web con su respectiva base de datos utilizando el servicio de hosting gratuito InfinityFree
. De esta manera, el aporte no será solo una maqueta visual, sino un software completamente funcional y accesible desde cualquier rincón del mundo en el año 2032
.
